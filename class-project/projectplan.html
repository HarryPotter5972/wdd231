My website plan

The purpose for my class projedt is to show off my hypothetical Zelda timeline based off of evidence from the Zelda games themselves. That is because I find the Official Zelda timeline released through Hyrule Historia and other books to be unsatisfactory. The target audience is fans of the Legend of Zelda franchise to show off my theory and its evidence.

Likely questions that are asked by a visitor to the site would be how an alternate way the Zelda games could link together.

The site name would be FanTimeline.net

The color scheme of the site would be green, red, and gold. The header's background would be red, the main background would be green, and the main color of the text would be gold. The fonts used would be Times New Roman.
